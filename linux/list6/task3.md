r -> pozwala wylistowac katalog (ls)
w -> pozwala tworzyc, usuwac i zmieniac nazwy plikow
x -> pozwala wejsc do katalogu (cd)

bez x -> katalog jest niedostepny
bez r -> nie zobaczysz listy plikow, ale moze dzialac jesli nas nazwy

sticky bit -> uzytkownik moze usuwac tylko swoje pliki (np dla /tmp) // oznaczany jako t na koncu

setgid -> nowe pliki dziedzicza grupe katalogu
